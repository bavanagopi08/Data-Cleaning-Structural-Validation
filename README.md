# Data Cleaning & Structural Validation

## Project Overview
This project focuses on transforming raw and unstructured marketing campaign data into a clean and reliable dataset.

## Dataset
Marketing Campaign Dataset (Kaggle).

## Tools Used
- Python
- CSV Module
- Regular Expressions
- Statistics Module

## Tasks Performed
1. Loaded the raw dataset.
2. Identified missing values.
3. Removed duplicate records.
4. Standardized column names.
5. Handled missing values.
6. Standardized date formats.
7. Performed structural validation.
8. Generated a cleaning report.

## Results
- Original Rows: 2240
- Original Columns: 29
- Missing Values Before: 24
- Missing Values After: 0
- Duplicate Records Removed: 0
- Cleaned Rows: 2240

## Output Files
- cleaned_marketing_campaign.csv
- cleaning_report.txt

## Conclusion
The data cleaning process was completed successfully. The cleaned dataset is ready for further analysis.
